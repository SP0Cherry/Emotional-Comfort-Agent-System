# 情感识别模块 MVP 阶段报告

日期：2026-11-02
状态：可运行原型
范围：普通话情感识别模块，不含人格建模、回复生成、方言识别和方言 TTS

## 1. 本阶段目标

用最小工程成本验证以下链路：

```text
用户文本 / 语音
        ↓
文本情绪分支 + 浏览器声学特征分支
        ↓
质量判断与可靠性加权融合
        ↓
情绪状态、多轮趋势、风险信号
        ↓
结构化接口与调试页面
```

本阶段优先解决接口、降级、隐私和可测试性，不以准确率结论为目标。

## 2. 已实现内容

### 文本分支

- 六类情绪概率：高兴、平静、悲伤、焦虑、烦躁、中性；
- 效价、唤醒度、强度与置信度；
- 否定表达与强度词处理；
- 中性和低信息输入的低置信度输出；
- 独立的自伤、他伤与严重绝望风险提示；
- 普通话常用情绪表达作为规则线索。

### 语音分支

- 浏览器请求麦克风后实时计算声学摘要；
- 提取有效语音比例、平均音量、音量变化、平均音高、音高变化、停顿次数和削波比例；
- 基于声学摘要估计高、中、低唤醒状态；
- 原始音频不发送到服务端；
- 音频过短、质量不足或浏览器不支持时自动降级。

### 本地模型分支

- 接入 `Qwen/Qwen2.5-1.5B-Instruct` 文本语义模型，运行在 MPS；
- 保留 `Johnson8187/Chinese-Emotion-Small` 作为可选文本分类器；
- 接入 `FunAudioLLM/SenseVoiceSmall` 语音转写模型，运行在 CPU；
- 接入 `emotion2vec/emotion2vec_plus_base` 九类语音情绪模型；
- 浏览器录音生成 16 kHz WAV，仅提交到本机模型服务；
- 模型调用有超时与规则回退；
- 非普通话方言代码进入接口后返回普通话 fallback，不伪装为已支持；
- 通过 `/api/v1/emotion/capabilities` 查询模型就绪状态。

### 融合与状态

- 根据语音质量进行有限权重融合；
- 声学分支不能脱离文本单独决定情绪正负性；
- 文本与语音可用时输出 `ok`，仅文本或质量不足时输出 `partial`；
- 最近五轮趋势、稳定性与低效价持续时间；
- 会话创建、查询、删除，默认四小时过期。

### 3.1 普通话基线说明

36 条回归样本覆盖六类情绪，规则基线的 Macro-F1 为 100%。这些样本与规则覆盖高度相关，只能证明规则没有回归，不能证明泛化。

7 条旧挑战样本用于错误分析。规则和融合在该开发集上达到 100%，但这是错误驱动调参后的结果，不能当作独立测试。为降低自证偏差，另建了 10 条全新留出集。

| 语料 | 规则 | Qwen | 规则 + Qwen |
| --- | ---: | ---: | ---: |
| 36 条回归集 | 100% | 86.1% | 97.2% |
| 7 条开发挑战集 | 100% | 57.1% | 100% |
| 10 条全新留出集 | 40% | 90% | 90% |

Qwen 明显提高未见语义的泛化，但仍会把普通事务句误判成平静。融合层在规则存在明确线索时限制模型权重为 8%，避免低质量模型覆盖已确认结果。

### 3.2 外部公开数据评测

为避免只在自己编写的样本上评估，新增两套外部数据：

1. `Chinese_Multi-Emotion_Dialogue`：MIT，650 条测试；存在标签噪声且无说话人字段。
2. `BRIGHTER Chinese`：CC-BY-4.0，从官方 test 分层抽取 1000 条；人工标注强度，无说话人字段。

BRIGHTER 结果：

| 方法 | Accuracy | Macro-F1 | UAR | 校准后 ECE |
| --- | ---: | ---: | ---: | ---: |
| 多数类基线 | 40.8% | 11.6% | 20.0% | 5.5% |
| 规则 | 29.6% | 24.3% | 29.7% | 3.9% |
| Qwen | 45.3% | 44.3% | 53.3% | 8.3% |
| 规则 + Qwen | 45.7% | 44.1% | 52.5% | 8.2% |
| Chinese-Emotion-Small | 44.4% | 38.0% | 40.9% | 3.7% |
| 组合训练 RoBERTa（同集） | 76.5% | 66.0% | 64.3% | 9.6% |
| 规则 + 组合模型 | 74.3% | 66.4% | 65.9% | 5.2% |

Qwen Accuracy 的 95% bootstrap 区间为 42.3%–48.5%，Macro-F1 区间为 41.4%–47.3%。主要错误是 226 条真实愤怒/烦躁被判成焦虑。Qwen 在 Macro-F1 上明显高于多数类，但绝对效果仍不足以宣称完成。

### 3.3 多任务微调

使用 BRIGHTER 官方 train 2445 条和另一套中文对话 train 2297 条训练 `hfl/chinese-roberta-wwm-ext`，联合优化五类主情绪、多标签情绪、负面/非负面和情绪强度。外部训练样本权重为 0.5。官方 dev 用于早停，最终使用未参与前一轮分析的 1449 条官方 test 补充集。

| 指标 | dev 190 条 | 密封 test 1449 条 |
| --- | ---: | ---: |
| Accuracy | 76.8% | 80.2% |
| Macro-F1 | 69.4% | 75.2% |
| 负面检测 F1 | 90.7% | 90.3% |
| 负面检测 Recall | 93.8% | 93.4% |

另一套数据的 650 条同源 test 上，模型达到 91.8% Accuracy、91.5% Macro-F1，焦虑 F1 88.9%、Recall 92.6%。这说明补充焦虑训练有效，但该测试与训练同源，不能当成跨数据集证据。

微调模型已接入应用并作为默认文本语义分支；普通情绪由模型主导，明确“平静”保留规则，模型失败后回退 Qwen。密封 BRIGHTER 测试没有焦虑样本，因此焦虑能力仍依赖同源验证。

在 dev 上拟合主分类头与多标签头融合权重时，搜索器选择了 0.5，但 test Macro-F1 从 66.0% 降到 63.0%，因此没有上线。多标签输出保留为辅助证据，最终决策继续使用更稳定的主分类头。

另训练了“中性门控 + 四类情绪细分类”的层级模型。它未超过扁平模型：BRIGHTER 密封 Accuracy 79.8% 对 80.2%，焦虑 test Accuracy 91.2% 对 91.8%，因此同样保留为离线实验。

## 4. 当前技术限制

1. Qwen 单句约 1.3～1.8 秒，现作为微调模型的失败回退。
2. 微调模型仍有中性/愤怒和悲伤/愤怒混淆。
3. SenseVoice 提供的是粗粒度情绪标签；emotion2vec 提供九类概率，但尚未在目标普通话数据上验证。
4. 当前没有置信度校准集，输出概率不能解释为统计置信水平。
5. 尚未验证真实嘈杂环境、多人说话、口音和反讽场景。
6. 风险规则只能用于演示级提醒，不能替代人工安全流程。
7. 方言接口只完成 fallback 契约，没有方言模型或校准。

## 5. 下一阶段实验要求

1. 采集小规模普通话自然对话验证集，并按说话人隔离。
2. 用真实数据校准微调文本模型与 emotion2vec。
3. 比较规则、Qwen、专用文本分类器、SenseVoice、emotion2vec 和不同融合权重。
4. 报告 Macro-F1、UAR、效价/唤醒度 MAE、ECE 和延迟。
5. 进行端到端用户感知测试，判断机器人是否显得过度诊断或冒犯。

## 6. 当前结论

本阶段已经形成可运行、可联调、隐私边界明确的普通话情感识别原型，完成 Qwen、SenseVoice、emotion2vec 三条本地模型链路的接入。下一阶段的瓶颈已从“没有模型”转为“没有真实数据与正式校准”。方言版本保留接口，但不进入本轮准确率声明。
