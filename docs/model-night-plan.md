# 情感模型后续工作夜间执行单

状态：已完成
开始时间：2026-11-01 晚
约束：仅普通话；方言只保留接口；不伪造数据或准确率。

## 目标

在现有规则 + Chinese-Emotion-Small + SenseVoiceSmall 基础上，尽可能完成所有无需新增真人实验即可执行的模型工作：

1. 对更适合简中短对话的文本模型做选型；
2. 引入专用语音情绪模型；
3. 做规则、文本模型、语音模型和融合的对照实验；
4. 建立置信度限制和失败回退；
5. 提供真实数据采集、标注和训练入口；
6. 输出周四可汇报的模型结论与限制。

## 明确不做

- 不声称完成方言识别；
- 不把规则回归集 100% 当成正式结果；
- 不训练需要大量算力的大模型；
- 不调用外部服务发送用户文本或音频；
- 不修改系统 Python；
- 不删除现有规则或模型缓存。
