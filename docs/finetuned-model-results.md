# 本地多任务 RoBERTa 微调结果

## 配置

- 基座：`hfl/chinese-roberta-wwm-ext`
- 训练集：BRIGHTER 中文官方 train 2445 条 + 另一套中文对话 train 2297 条
- 外部训练样本权重：0.5，避免标签噪声压过 BRIGHTER 金标准
- 验证集：BRIGHTER 中文官方 dev，190 条
- 密封测试集：官方 test 中未参与前一轮错误分析的 1449 条
- 设备：Apple M5 MPS
- 训练：3 epoch，batch size 8，max length 192，冻结前 6 层
- 联合目标：
  - 五类主情绪交叉熵；
  - 五类多标签 BCE；
  - 负面/非负面 BCE；
  - 五类情绪强度 SmoothL1。

| 真实 \ 预测 | 高兴 | 悲伤 | 愤怒/烦躁 | 中性 |
| --- | ---: | ---: | ---: | ---: |
| 高兴 | 253 | 13 | 8 | 23 |

| 中性 | 12 | 10 | 99 | 220 |

密封测试集没有焦虑样本，因为官方 test 中仅有的 39 条焦虑样本已全部进入前一轮开发评测。因此本轮不能报告焦虑类在未见测试上的泛化结果。

## 与提示式模型比较

| 模型 | Accuracy | Macro-F1 |
| --- | ---: | ---: |
| Qwen 少样本提示（1000 条开发测试） | 45.3% | 44.3% |
| 多任务 RoBERTa（1449 条密封测试） | 80.2% | 75.2% |

为了进行严格同集对照，微调模型也在 Qwen 使用过的 1000 条 BRIGHTER 测试样本上运行：

| 方法 | Accuracy | Macro-F1 | 校准后 ECE |
| --- | ---: | ---: | ---: |
| Qwen 少样本提示 | 45.3% | 44.3% | 8.3% |
| 组合训练 RoBERTa | 76.5% | 66.0% | 9.6% |
| 规则 + 组合模型 | 74.3% | 66.4% | 5.2% |

同集对照中，微调模型 Accuracy 比 Qwen 高 31.2 个百分点，Macro-F1 高 21.7 个百分点。

固定 70/30 的主分类头与多标签头融合也已实测，但 Macro-F1 从 66.0% 降到 63.8%，因此默认决策恢复主分类头。多标签概率继续作为辅助证据输出，等有足够 dev 数据后单独拟合门控权重。

之后只在 dev 上搜索融合权重，搜索器选择 0.5，dev Macro-F1 为 72.7%；但未参与搜索的 test Macro-F1 只有 63.0%，低于主分类头的 66.0%。因此该 dev 选择没有上线。详细记录见 [输出策略调参](brighter-output-tuning.md)。

### 层级模型实验

使用已微调编码器的冻结表示训练“中性门控 + 情绪细分类”二级头：

| 数据 | 扁平模型 | 层级模型 |
| --- | ---: | ---: |
| BRIGHTER 密封 Accuracy | 80.2% | 79.8% |
| BRIGHTER 密封 Macro-F1 | 75.2% | 75.2% |
| 同源焦虑 test Accuracy | 91.8% | 91.2% |
| 同源焦虑 test Macro-F1 | 91.5% | 91.0% |

层级模型在 dev 上略高，但没有在密封测试和焦虑 test 上胜出，因此没有替换默认模型。记录在 `models/hierarchical-stacker/metrics.json`。

## 跨数据集焦虑验证

组合模型参与训练的另一套数据，其独立 test split 含 650 条：

| 指标 | 结果 |
| --- | ---: |
| Accuracy | 91.8% |
| Macro-F1 | 91.5% |
| 焦虑 F1 | 88.9% |
| 焦虑 Recall | 92.6% |
| 焦虑 Precision | 85.5% |

这是同源 train/test 留出结果，不是新的跨数据集泛化结果；它验证了通过增加焦虑训练样本可以解决原来的焦虑召回短板。

## 限制

- 数据没有说话人字段，不能声称说话人隔离。
- BRIGHTER 密封测试没有焦虑，焦虑能力依赖另一套同源留出验证。
- 情绪类别和文本风格仍与真实陪伴对话存在差异。
- 当前封闭测试主要覆盖高兴、悲伤、愤怒/烦躁和中性。
- 仍需使用真实陪伴场景的人类对话验证。

## 低置信度决策

密封测试中，不同置信度阈值对应：

| 置信度门槛 | 覆盖率 | 覆盖样本 Accuracy |
| ---: | ---: | ---: |
| 0.5 | 94.9% | 82.5% |
| 0.7 | 81.1% | 86.1% |
| 0.8 | 70.7% | 89.1% |
| 0.9 | 46.4% | 94.7% |

接口新增 `decision_mode`：`confident`、`tentative`、`clarify`。低置信度时不再强行输出细粒度情绪。

模型文件：`models/brighter-johnson-multitask/`
逐条密封预测：`models/brighter-johnson-multitask/sealed-predictions.jsonl`
