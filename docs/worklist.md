# 情感识别 MVP 工作清单

状态：普通话三模型版本完成，服务运行中

## 本轮目标

交付一个无需安装第三方依赖、可直接在本机运行的普通话情感识别 MVP。它能返回六类情绪、效价、唤醒度、强度、置信度、陪伴线索和风险信号，并跟踪同一会话中的情绪变化。
