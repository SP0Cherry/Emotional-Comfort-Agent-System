# 外部普通话情绪基准与校准执行单

状态：完成（语音数据受访问许可阻塞）
开始时间：2026-11-02

## 目标

把评测从手写小样本升级为可追溯的外部数据评测：

1. 至少数百条普通话情绪样本；
2. 有明确来源、许可证和标签映射；
3. 按对话或说话人切分，避免上下文泄漏；
4. 对比规则、Qwen、专用文本模型和融合；
5. 报告宏平均指标、混淆矩阵、bootstrap 置信区间与校准；
6. 所有步骤可以由脚本重复运行。

## 数据选择原则

- 优先普通话或简体中文；
- 优先对话、自然表达，而不是单句表演；
- 标签可稳定映射到 joy、calm、sadness、anxiety、anger_irritation、neutral；
- 有对话 ID、说话人或可识别的分组字段；
- 许可证允许研究使用，并记录来源与限制；
- 不绕过登录、不规避访问控制、不把训练集伪装成独立测试集。

## 停止条件

- 候选数据需要登录或无法确认许可；
- 标签无法可靠映射；
- 数据下载超过 3 GB 或磁盘低于 40 GB；
- 数据转换出现不可恢复的泄漏或完整性问题。

遇到上述情况不终止整个任务，应转向下一候选数据源或完成评测工具。
