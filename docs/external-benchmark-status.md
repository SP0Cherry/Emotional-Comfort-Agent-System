| 方法 | Accuracy | Macro-F1 | UAR | 校准后 ECE |

| 多数类基线 | 40.8% | 11.6% | 20.0% | 5.5% |

| 规则 + 组合模型 | 74.3% | 66.4% | 65.9% | 5.2% |

Qwen 在 1000 条 test 上的 Accuracy 95% CI 为 42.3%–48.5%，Macro-F1 CI 为 41.4%–47.3%。主要混淆是把 226 条真实愤怒/烦躁判成焦虑。

同集微调模型 Accuracy 95% CI 为 74.0%–79.3%，Macro-F1 CI 为 62.0%–69.8%。它把主要混淆从“愤怒→焦虑”转变为“中性/愤怒边界”，整体细粒度能力显著提高。

密封 1449 条官方 test 补充集上的组合模型 Accuracy 为 80.2%，Macro-F1 为 75.2%，负面检测 F1 为 90.3%。该数据没有焦虑样本，因此焦虑能力由另一套数据的同源 test 补充验证。

- 原始标签存在可见噪声；

- 本轮只能评价文本，不评价语音准确率。
- BRIGHTER 没有说话人或对话分组字段，仍是官方划分但不是说话人隔离测试。
