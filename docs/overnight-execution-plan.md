# 通宵自主执行单

状态：执行中
创建时间：2026-11-01 晚
目标截止：2026-11-05 周四交付前

## 1. 最终目标

把当前普通话规则原型升级为“真实模型可接入、失败可回退、接口稳定”的普通话情感识别模块，并完整保留未来方言扩展接口。

最终必须满足：

1. 现有 `npm start` 和 `npm test` 仍然可用；
2. 规则基线可在模型不可用时自动降级；
3. 文本模型至少完成一次真实推理并记录实际结果；
4. 语音模型至少完成一次真实推理并记录实际结果；
5. 方言代码可传入接口，但明确返回“普通话回退、尚未校准”；
6. 生成可在周四汇报的实验结果、限制和运行说明。

## 2. 执行边界

允许：

- 在工作区内创建 `.venv`、模型缓存、临时音频和输出文件；
- 下载公开模型与 Python 包；
- 启动仅监听 `127.0.0.1` 的本地服务；
- 安装项目本地依赖；
- 修改本项目代码、测试与文档。

禁止：

- 安装到系统 Python 或覆盖系统包；
- 修改工作区外文件；
- 删除用户文件或现有模型缓存；
- 读取、打印或上传 API Key、密钥和身份信息；
- 向外部服务发送用户录音或对话；
- 开放局域网端口；
- 使用高资源全量训练；
- 在现有方案未通过回归测试时删除规则回退。

## 3. 资源预算

| 资源 | 上限 |
| --- | --- |
| 新增磁盘 | 12 GB |
| 模型常驻内存 | 8 GB |
| 安装时间 | 单次最多 40 分钟 |
| 模型下载 | 单次最多 40 分钟 |
| 单次测试 | 最多 5 分钟 |
| 失败重试 | 同一原因最多 3 次 |

若磁盘可用空间低于 40 GB、出现明显系统卡顿或内存压力，停止模型下载，保留当前基线并完成报告。

## 4. 决策顺序

1. 先确认 Python 3.11/3.12，再创建项目内 `.venv`；
2. 先跑文本模型，成功后再装语音模型；
3. 优先使用 CPU 推理；MPS 只在已验证兼容时启用；
4. 优先 `SenseVoiceSmall` 官方支持路径；遇到安装冲突不破坏已有 Python 环境；
5. 模型不可用时保留浏览器声学摘要作为降级语音分支；
6. 所有模型调用都设置超时，失败时回退到规则基线；
7. 不为追求演示效果伪造准确率，保留挑战集失败案例。

## 7. 停止条件

只有以下情况可以停止并留下一次夜间运行报告：

- 同一安装或下载问题连续 3 次失败；
- Python、PyTorch 或 FunASR 与当前 Apple Silicon 环境不兼容；
- 下载后超过资源预算；
- 需要用户登录、接受许可证或提供 API Key；
- 继续操作可能导致系统不稳定或覆盖用户数据。

模型不可用不是停止交付的理由。应完成：

- 规则/声学回退；
- 方言接口 fallback；
- 自动化测试；
- 已知问题与替代方案。
