# 普通话情感数据采集规范

## 目标

为真实模型评测和后续微调准备小规模普通话自然对话数据。第一轮目标不是大规模训练，而是尽快发现当前模型在真实场景中的错误。

首轮建议：

- 3～5 名说话人；
- 每人 20～30 条；
- 总时长约 30～60 分钟；
- 六类情绪尽量平衡；
- 同一说话人不得同时出现在训练集和测试集。

## 采集前

- 获得录音与标注用途的明确同意；
- 说明数据只用于本项目研究；
- 不采集姓名、电话、住址等直接身份信息；
- 不使用真实危机经历作为表演素材；
- 说话人可以随时停止并删除自己的样本。

## 采集方式

每名说话人记录以下三类内容：

1. 日常陈述，例如“今天下午三点开会”；
2. 带情绪的自然表达，例如“最近做什么都没意思”；
3. 同一含义的平静与强烈表达。

不要要求每个人用夸张播音腔表演。优先保留自然语速、停顿、口音和生活化表达。

建议录音参数：

- 16 kHz 或 48 kHz；
- 单声道；
- PCM WAV；
- 每条 1～15 秒；
- 环境尽量安静；
- 保留少量低噪声与设备差异样本。

## 标注字段

每条样本至少记录：

```json
{
  "sample_id": "spk01-0001",
  "speaker_id": "spk01",
  "split": "train",
  "audio_path": "data/audio/spk01-0001.wav",
  "text": "最近做什么都提不起劲。",
  "emotion": "sadness",
  "valence": -0.7,
  "arousal": 0.3,
  "intensity": 0.7,
  "consent": true
}
```

情绪枚举：`joy`、`calm`、`sadness`、`anxiety`、`anger_irritation`、`neutral`。

数值范围：

- `valence`：`[-1, 1]`
- `arousal`：`[0, 1]`
- `intensity`：`[0, 1]`

若多人标注，额外增加：

- `annotator_1`
- `annotator_2`
- `agreement_notes`

意见不一致时保留差异，不要强行改成单一答案。

## 数据划分

推荐按说话人划分：

- 5 人：3 人训练、1 人验证、1 人测试；
- 3 人：1 人训练、1 人验证、1 人测试；
- 少于 3 人时只做错误分析，不报告泛化准确率。

不得把同一说话人的不同音频随机分到不同集合，否则结果会虚高。

## 校验

把元数据保存为 JSONL 后运行：

```bash
npm run validate:data -- data/emotion-samples.jsonl
```

校验器会检查：

- 必填字段和情绪枚举；
- 数值范围；
- sample_id 是否重复；
- 说话人是否跨训练/验证/测试泄漏；
- 音频文件是否存在；
- 每类、每说话人和每划分的样本量。

## 模型实验

首轮先比较：

1. 规则；
2. Qwen 少样本提示分类；
3. Chinese-Emotion-Small；
4. 规则 + Qwen；
5. 文本 + emotion2vec + SenseVoice 融合。

真实测试集的准确率优先于旧回归集。旧回归集只用于防回归。
